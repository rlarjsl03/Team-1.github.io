COOPERATIVE LOCALIZATION

자율주행 차량은 서로의 위치를 어떻게 도와줄까?

혼자 찾는 위치보다, 함께 찾는 위치가 더 정확하다. 자율주행 차량들이 서로의 위치와 센서 정보를 공유하여 위치 추정을 개선하는 Cooperative Localization을 알아보자.

01

What is Localization?

“자율주행 차량은 자신의 위치를 어떻게 알까?”

Localization은 자율주행 차량이 자신의 현재 위치와 자세를 추정하는 기술이다. 차량은 GNSS, IMU, LiDAR, Camera 같은 센서 정보를 결합해 지도 또는 세계 좌표 안에서 자신이 어디에 있고 어느 방향을 보고 있는지 계산한다.

Selected Sensor

GNSS

위성 신호를 이용해 차량의 전역 위치를 추정한다.

Why Isn't Localization Perfect?

실제 환경에서는 센서가 항상 완벽하지 않다. 신호가 끊기거나, 노이즈가 섞이거나, 이전 위치를 누적해서 추정하는 과정에서 오차가 조금씩 커질 수 있다.

03

Cooperative Localization

Cooperative Localization은 여러 자율주행·자율운항 차량이 서로의 위치 정보, 상대 거리 측정값, 센서 정보 또는 상태 추정 정보를 공유하여 각 차량의 위치추정을 개선하는 기술이다. 적절하고 신뢰할 수 있는 통신과 상대 측정이 있을 때 효과를 기대할 수 있다.

Position Velocity Heading Relative Distance Sensor Data
04

How Does It Work?

Estimate

각 차량이 자신의 센서를 이용해 위치를 추정한다.

GNSS + IMU + Sensor Data Initial Position Estimate

Communicate

차량들이 위치 관련 정보를 서로 교환한다.

Vehicle A ↔ Communication Vehicle B

Cooperate

자신의 센서 정보와 다른 차량의 정보를 결합한다.

My Sensor Data Other Vehicle Data Relative Measurement Sensor Fusion / State Estimation Improved Position Estimate
05

Independent vs Cooperative

중앙 슬라이더를 움직여 차량들이 독립적으로 위치를 추정하는 상태와 협력하는 상태를 비교해보자.

Independent Localization

각 차량이 자신의 센서 정보만 사용하여 위치를 추정한다.

Cooperative Localization

자신의 센서 정보와 다른 차량의 정보를 함께 사용한다.

Case Study — Autonomous Underwater Vehicle

“GPS가 닿지 않는 바닷속에서는 어떻게 위치를 찾을까?”

AUV는 수중에서 GNSS를 직접 이용하기 어렵기 때문에 INS, DVL, Acoustic Positioning 등의 기술을 이용해 위치를 추정한다. 그래서 다른 AUV와 협력해 상대 측정과 항법 정보를 활용하는 Cooperative Localization이 중요한 응용 사례가 된다.
